## 扩展列表

| 扩展                           | 说明                                                                                                                  |
| ------------------------------ | --------------------------------------------------------------------------------------------------------------------- |
| `pi-provider-kimi-code`        | **Kimi Code 提供者** — 复用 Kimi Code Plan 于 pi-coding-agent，支持 K2.6、K2.5 等模型。                               |
| `pi-tool-display`              | **工具显示优化** — 紧凑的工具调用渲染、diff 可视化与输出截断。可隐藏、折叠并截断冗长的工具输出，使 TUI 界面更加简洁。 |
| `@tmustier/pi-usage-extension` | **使用统计面板** — 为 Pi 会话提供用量统计仪表盘，帮助追踪和分析使用情况。                                             |
| `@ollama/pi-web-search`        | **网页搜索与抓取** — 基于 Ollama 的 web_search 和 web_fetch API，为 Pi agent 提供联网搜索和网页内容提取能力。         |
| `pi-lens`                      | **实时代码反馈** — 提供 LSP、代码检查、格式化、类型检查、结构分析等实时代码质量反馈。                                 |
| `pi-wierd-statusline`          | **状态栏美化** — 极简 Tokyo Night 风格的状态栏底部扩展，美化 pi coding agent 的界面状态显示。                         |
| `pi-btw`                       | **并行边栏对话** — 支持通过 `/btw` 命令开启并行的侧边对话，便于在主线任务外进行辅助交流。                             |
